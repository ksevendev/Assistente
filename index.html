Versões

v2.0 ou v3.0?

Ambas são estáveis. A v3.0 é a v2.0 com uma camada de inteligência em cima.

Estável
v2.0

Assistente distribuído completo. Ideal para automação doméstica e controle de rede.

  • Dashboard web com 4 abas e sparklines em tempo real
  • Descoberta mDNS — nós se encontram sem config de IP
  • Terminal remoto com histórico e coloração semântica
  • Auto-update via GitHub com credencial Base64 distribuída
  • Wake-on-LAN, SSH, playerctl e controle de voz
  • Autenticação Flask-Login + SQLite + audit log
  • Master/Worker — separa dashboard de nós headless
★ Recomendado
v3.0

Tudo da v2.0 mais uma camada de IA que lê seus projetos e conversa sobre eles.

  • Tudo da v2.0 incluído
  • Chat de Mentoria — conversa sobre seus projetos com RAG
  • Memória semântica — ChromaDB + sentence-transformers
  • Memória episódica — SQLite com histórico de interações
  • Consciência situacional — analisa logs e detecta falhas
  • Autonomia supervisionada — propõe ações, aguarda seu OK
  • Personalidade — Seven (calmo) ou Spark (direto)
  • Ollama/Gemini/Fallback — funciona sem internet
★ Recomendamos a v3.0 para novos projetos. O instalador pergunta.

Como o KSigner lida com a assinatura de documentos PDF?
Seven responde
O KSigner usa a biblioteca cryptography com RSA-PSS para assinar. O fluxo está em signer/core.py: extrai o hash SHA-256 do PDF, assina com a chave privada e serializa em PKCS#7. A verificação usa a chave pública do certificado armazenado no PostgreSQL. Encontrei um ponto de melhoria: a função validate_cert_chain() não verifica CRL — isso pode ser um risco em produção.

Perguntas Frequentes

Qual a diferença entre v2.0 e v3.0?
A v2.0 é o assistente distribuído completo — dashboard, mDNS, terminal, auto-update, voz. A v3.0 adiciona uma camada de IA: indexa seus repositórios no ChromaDB, expõe um chat no dashboard onde você pode perguntar sobre seus projetos (RAG), detecta anomalias nos nós e propõe soluções aguardando sua aprovação. O instalador pergunta qual você quer — não precisa decidir antes.
Preciso do Ollama ou de uma chave Gemini para a v3.0?
Não obrigatoriamente. A v3.0 tem um fallback RAG que funciona sem LLM — responde usando apenas os trechos de código indexados. Mas para respostas elaboradas o Ollama é recomendado (gratuito, local, privado). O instalador pergunta qual backend você quer durante a configuração.
O instalador configura o config.py automaticamente?
Sim. O wizard pergunta: versão, nó (seven/spark/mobile), modo (master/worker), IPs e MACs da rede, usuário/senha do dashboard, segredos criptograficamente gerados, credenciais GitHub para auto-update e configuração de IA (v3). O arquivo config.py final é gerado com todos esses valores preenchidos. Você pode passar --yes para aceitar todos os defaults.
Funciona sem microfone?
Sim. Sem microfone o sistema usa input por teclado ou fica apenas como servidor API. Todos os comandos disponíveis por voz também estão no dashboard e na API REST.
Como funciona a "Autonomia Supervisionada" da v3.0?
A IA monitora os logs de /health de cada nó e detecta padrões de erro (disco cheio, OOM, timeout). Quando identifica um problema, propõe uma solução (ex: limpar /tmp, reiniciar serviço) registrando uma "ação pendente" no banco. O dashboard exibe um card amarelo pedindo sua aprovação. A ação só executa quando você clica "Aprovar" — ou diz "Seven, pode executar" por voz.
Como desinstalar?
./uninstall.sh remove o .venv, scripts e temporários preservando config.py e dados. --full remove o diretório inteiro. --keep-data preserva o banco SQLite. --dry-run mostra o que seria removido sem remover nada. No Windows: .\uninstall.ps1 com os mesmos flags em camelCase.
