Funcionalidades

Tudo que você precisa

Do reconhecimento de voz ao auto-update via GitHub — em um único projeto Python.

📡
Descoberta mDNS Automática
Nós se encontram na rede local via Zeroconf/mDNS sem configuração manual de IPs. Adicione um novo nó e ele aparece no dashboard em segundos.
📊
Dashboard em Tempo Real
Sparklines SVG de CPU e RAM com polling de 5 segundos. Quatro abas: Nós, Métricas, Update e Broadcast. Drawer lateral com informações detalhadas por nó.
🔄
Auto-Update via GitHub
Credencial Base64 armazenada em config.py com decodificação distribuída em três funções independentes em updater.py. Nunca expõe o token nos logs.
💻
Terminal Remoto Integrado
Terminal com histórico ↑↓, Ctrl+C, Ctrl+L, coloração semântica e copy de output. Executa comandos em qualquer nó da rede sem sair do dashboard.
🎙️
Controle por Voz
STT via Google Speech Recognition com filtragem por nome do assistente. Hot-reload de módulos em runtime sem reiniciar. TTS via espeak-ng ou gTTS.
🔐
Autenticação em Camadas
Sessão Flask com senha pbkdf2:sha256, API_SECRET para chamadas inter-nós, ADMIN_SECRET para operações root. Audit log completo em SQLite.
🧩
Módulos Hot-Reload
Crie commands/meu_modulo.py e diga "Seven, recarregar módulos". Nenhum reinício necessário. Protocolo simples: DESCRIPTION + COMMANDS dict.
⚡
Wake-on-LAN + SSH
Acorda PCs remotos com Magic Packet UDP. Executa comandos via SSH autenticado por chave RSA. Controla playerctl e VS Code em máquinas remotas.

Instalação

Pronto em minutos

Um instalador unificado para Linux, macOS e Termux. Windows via PowerShell.

git clone https://github.com/ksevendev/Assistente.git && cd k7-core
chmod +x install.sh && ./install.sh --node seven
./run_seven.sh
Nota: Requer Python 3.10+. O instalador configura o venv, instala espeak-ng, portaudio e gera a chave SSH automaticamente. Compatível com Debian 12, Ubuntu 24.04, Arch Linux e macOS.
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\install.ps1 -Node seven
.\run_seven.bat
Nota: Execute o PowerShell como Administrador. O instalador usa winget para instalar dependências, cria atalho no Desktop e opcionalmente registra o serviço Windows via NSSM.
pkg install python git && git clone https://github.com/ksevendev/Assistente.git
cd k7-core && chmod +x install.sh && ./install.sh --termux
python core.py
Nota: Instale o app Termux:API pela F-Droid para TTS, vibração e notificações. NODE_TYPE é definido automaticamente como "mobile".
curl -fsSL https://raw.githubusercontent.com/ksevendev/Assistente/main/install.sh | bash
curl -fsSL https://raw.githubusercontent.com/ksevendev/Assistente/main/install.sh | bash -s -- --node spark --no-voice
Instalação headless (Worker): use --no-voice para pular PyAudio e espeak. Ideal para servidores sem interface gráfica. O Worker ainda aceita comandos remotos pela API.

Desinstalação

# Linux / macOS / Termux
./uninstall.sh # remove .venv, scripts, tmp, logs
./uninstall.sh --full # remove tudo incluindo o diretório
./uninstall.sh --keep-data --keep-config # preserva banco e config
# Windows PowerShell
.\uninstall.ps1 -Full # remove tudo
.\uninstall.ps1 -DryRun # simulação — mostra o que seria removido
Dúvidas

Perguntas frequentes

Preciso configurar IPs manualmente?
Não. Com mDNS funcionando (padrão em redes domésticas), todos os nós se descobrem automaticamente. O campo "ip" em NETWORK_NODES pode ficar vazio. Configure IPs estáticos apenas como fallback em redes que bloqueiam mDNS.
Funciona sem microfone?
Sim. Sem microfone o sistema entra em modo texto (input pelo teclado) ou modo servidor (apenas API REST). Todos os comandos disponíveis por voz também estão disponíveis via dashboard web e API curl.
Como adicionar novos comandos?
Crie um arquivo .py em commands/ com um dicionário COMMANDS mapeando strings para funções. Depois diga "Seven, recarregar módulos" — o novo comando fica disponível imediatamente sem reiniciar.
A credencial do GitHub é segura?
O token é armazenado como Base64 opaco em config.py. A decodificação está distribuída em três funções independentes em updater.py (linhas ~63, ~101 e ~160), sem função auxiliar central. O token nunca aparece em logs — é mascarado por _redact() antes de qualquer saída. Recomendamos usar um Fine-grained PAT com acesso apenas ao repositório k7-core.
Posso usar na internet (fora da rede local)?
O k7-core foi projetado para redes locais. Para acesso externo, use uma VPN (WireGuard ou Tailscale) — isso é mais seguro do que expor a porta 2026 diretamente na internet. Nunca exponha o dashboard sem HTTPS em redes públicas.
Qual a diferença entre Master e Worker?
O Master sobe o dashboard completo com autenticação, banco SQLite, todas as rotas /api/* e o buscador mDNS. O Worker sobe apenas /cmd e /health — headless, sem templates HTML. Configure com NODE_MODE="worker" ou ENABLE_DASHBOARD=False.

Pronto para começar?

Um comando para instalar. Três nós na rede. Controle total pelo browser.
